# Excel 批量处理规范

当输入是 Excel 时，输出结构必须明确且固定，避免把多个设备汇总到同一格。

## 输入处理

对 Excel 的每一行执行以下步骤：

1. 读取该行内容
2. 提取其中的设备标识
3. 如果同一行中有多个设备，按逗号分隔后拆成多个设备
4. 对每个设备分别执行完整查询流程
5. 输出时按**一行一设备**写入结果 Excel

如果同一输入行里只有 1 台设备，则输出 1 行；如果同一输入行里有多台设备，则这些设备在输出中各占 1 行，但必须保留它们来自同一输入行的标记。

## 输出列定义

输出 Excel 仅包含以下 6 列，顺序固定，不得新增或删除字段：

| 列名 | 说明 |
|------|------|
| `输入序号` | 对应输入 Excel 的原始行序号。同一输入行拆出的多台设备共享同一个值 |
| `行内设备序号` | 该设备是原始行内拆出的第几个设备，从 `1` 开始 |
| `设备标识` | 当前输出行对应的单个设备 ID |
| `绑定状态` | 最终结论，只允许 `已绑定` / `未绑定` / `查询失败` |
| `在线状态` | `在线` / `离线` / 留空 / `查询失败` |
| `错误信息` | 失败原因，成功时留空 |

## 输出约束

- 输出必须是**一行一设备**。
- 同一输入行拆出的多台设备，`输入序号`相同，`行内设备序号`递增。
- 输出字段必须严格为以下 6 列且顺序固定：`输入序号`、`行内设备序号`、`设备标识`、`绑定状态`、`在线状态`、`错误信息`。
- 不允许把同一输入行的多个设备拼成一段文本后放进单个单元格。
- 不允许只输出"第 N 行有 3 台设备"这种汇总结果而不展开到设备级。
- 如果某台设备查询失败，也应保留该设备对应的一行结果，避免静默丢失。

## 示例

输入 Excel：

| 输入行 | 设备列内容 |
|--------|------------|
| 1 | `AIC1JPE1S1A1003` |
| 2 | `KC3NQXFBED2247,28d61f9dc94ce3212e23ad67a9428e95` |

输出 Excel：

| 输入序号 | 行内设备序号 | 设备标识 | 绑定状态 | 在线状态 | 错误信息 |
|----------|--------------|----------|----------|----------|----------|
| 1 | 1 | `AIC1JPE1S1A1003` | 已绑定 | 在线 |  |
| 2 | 1 | `KC3NQXFBED2247` | 未绑定 |  |  |
| 2 | 2 | `28d61f9dc94ce3212e23ad67a9428e95` | 已绑定 | 离线 |  |
