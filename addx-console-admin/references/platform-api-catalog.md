离线复扫（不登录、不调业务 API）：

```bash
python3 skills/delivery/cicd-platform/scripts/scan_platform_api.py --root /tmp/internal-business-source/console --kind java --output skills/business-operations/addx-console-admin/references/source-api-catalog.json

```

Snapshot 元数据为该目录 manifest.json；Go 读取全部 handler/router/request/response/model 文件，Java 读取完整 src/main/java（不读配置、.env）。snapshotCoverage 缺文件时不可声明完整。反射、框架生成、Actuator/Swagger/第三方组件端点不属于静态业务 Controller 清单；使用各组件官方文档，不复制成平台自有 API。

业务覆盖（76 个静态业务 Controller、481 条路由）：

| Skill 菜单 | 源码 Controller / API family | 覆盖与缺口 |
|---|---|---|
| App管理 | CustomerPolicy、CustomerAppStoreImg /customer、截图 | 协议读写/素材；废弃页面及协议模板无当前 FE 证明，blocked |
| 云服务管理 | sharing/*、CloudOemOrder、DevideCost /cloud、/revenue、/devide | 商品/账单/收益/成本/分成读写与导出；按模型资源范围 |
| 4G增值服务 | sharing/DeviceSim、4G 分成相关 Controller | API 见全部表；菜单到每个 family 的精确映射缺 Console FE，blocked |
| 产品管理 | model/*、FileCenter /device、/model、/battery、/file | 硬件/App/母版/部件/类别/文件/发布；固件构建菜单缺精确前端映射 |
| 生产管理 | Factory、Produce*、TestItem*、Matter*、UserSn*、Battery*、Pack* | 生产/测试/追溯/证书/SN/电池/第三方；路由与类型齐备，页面映射缺 FE |
| 运营管理 | UserTicket、AfterSales、运营相关 Controller | 工单/售后；Slot/Creative 若清单未提供源入口，则 blocked，不能猜接口 |
| 内部工具 | IotTool、IotManage、RecordingCodec、CodeRules、iot/* | 设备配置/兑换/日志/IoT订阅与VIP；高影响外部写必须单次授权和回读 |
| 权限管理 | Permission、User、Account | 用户/角色/路由权限；真实页面 grant 由 CLIENT/SERVER 注解核验 |

权限链必须同时读取 framework/WebMvcConfig.java、TokenInterceptor.java、authorization/{ClientAccessible,ServerAccessible,*PermissionKeys}.java、LoginCacheService.java 与业务 service。CLIENT 没有 ClientAccessible 默认拒绝；SERVER 没有 ServerAccessible 保留认证访问；有 anyOf 则需至少一个 page key，方法注解覆盖类注解。此为源码行为，不是用户已有权限证明；实际角色/grant未知时写 blocked。/skill-api/** 使用独立 SkillApiInterceptor，不能复用普通 token 或把 forward 当任意 API 代理。Webhook、merge/decline、customer/model/sync 及 WebMvcConfig 排除路径不受同一 TokenInterceptor；外部回调身份需单独证明，禁止当普通用户可执行写命令。

POST 不等于写：/cloud/oem/order/list、/info 控制器分别调用 OemOrderService.queryOemOrderList/queryOemOrderInfo；源码使用 selectList/selectPage 与条件过滤，是账单查询。/devide/cost/save 虽 handler 名为 queryRevenueShare，但调用 saveDevideCost/saveDefaultCoefficient/saveDeviceNumCoefficientDOBatch，必须视为写。其他 route 的 query/read-candidate 表示调用链待核验，不能仅凭 query/list 名称放行。

发布副作用：/device/release/submit/task 的 type=6 分发 BatchAppFunctionReleaseService，其他类型走 DeviceReleaseService；create-pr 会创建分支/PR，sync-pr-status 可能执行发布回调，不是普通查询。取消任务 /release/task/{id}/delete 不保证撤回已经发布版本。写后回读 GET /device/release/release/tasks/{type}?taskId=<id> 与 PR 状态；merge/decline 是外部回调，blocked。其他保存后同资源查询必须比较 ID、版本、完整字段和范围，未知回读不得发起写。

缺口：只取得 Console 后端仓库，未提供其前端固定 SHA，不能证明全部80+菜单、80+页面或 UI enabled/权限呈现。扫描不把这种缺口当 runtime 支持，也不凭现有88端点文档补造未注册端点。任何动态路由或模型缺入口在 JSON 明示，必须补证据后执行。
