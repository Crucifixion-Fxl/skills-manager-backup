Timestamp assignment is not CAS. Error-prone logging and metadata lookup can occur after mutations.

Parameters are a complete replacement: edit deletes all target parameter rows, updates parent, reinserts the submitted list. Full raw parameter state, exact target/immutable code, strict desired schema and deletion acknowledgements are necessary.

It additionally deletes every managed model test-item configuration matching that relation's item/art pair, across all models/factories.
