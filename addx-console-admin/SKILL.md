# addx-console-admin

A4x 内部管理后台 (console.addx.live) 操作助手。优先使用已验证的原生 API/OpenCLI；浏览器用于登录、缺口操作和网页对照。

- 页面操作指南见下方各模块说明
- 多型号 App 配置修改与一个 PR 发布：先读 [references/batch-app-function-release.md](references/batch-app-function-release.md)，适用 API 批量工作流、环境范围和授权规则均在该文档；不套用硬件多型号发布。
- 完整 API 端点参考（备选方案）见 [references/api-reference.md](references/api-reference.md)

## Description

首次接入/变更扫描与日常认证入口见 [SaaS 接入](references/saas-access.md)；已有平台业务契约与授权门禁仍在本 Skill 维护。

此 Skill 记录 A4x 后台业务操作方法。下面的模块目录不是接口完整性或真实验收证明；实际范围以部署路由、用户权限和逐动作证据为准：

| 模块 | 路由前缀 | 核心功能 |
|------|---------|---------|
| App管理 | `/app-management/` | 协议配置（服务端）、截图工具。⚠️ 客户端协议配置和协议模板管理页面已弃用 |
| 云服务管理 | `/sharing/` | 收益统计、客户/工厂分成规则、商品、账单、收入报表、成本设置 |
| 4G增值服务 | `/4g-service/` | 分成协议管理、增值收益统计、SIM卡统计查询 |
| 产品管理 | `/product/` | 硬件规格、套餐白名单、App功能配置、部件/部件组、设备类别、电量计、文件中心、固件构建 |
| 生产管理 | `/production/` | 生产账号、CUID/出厂统计、测试项、发布、工艺方案、证书(DAC/CD)、SN号、电池、三方对接 |

| 权限管理 | `/authority/` | 客户端/服务端用户管理、角色管理、路由管理 |

## Rules

### 浏览器辅助

复用任务已授权的浏览器控制工具，不强制安装或切换浏览器。需要使用 `agent-browser` 且本机没有可用控制能力时，其安装方式为：

```bash
npx skills add vercel-labs/agent-browser --skill agent-browser --agent claude-code -y
```

基本用法（open → snapshot → interact）：

```bash
agent-browser open https://console.addx.live/
agent-browser snapshot -i   # 获取元素引用 @e1, @e2...
agent-browser click @e3
agent-browser fill @e1 "username"
agent-browser wait --load networkidle
```

### 操作原则

1. **原生 CLI/API 优先** — 已有授权原生凭据与可用 API 时优先原生消费；浏览器用于登录、授权、真实 API 缺口与最小结果对照
2. **部署契约核验** — API 与权限依据当前实例实际契约；不为统一工具安装而阻断已有原生 HTTP 路径。按部署证明只读操作，不能凭 HTTP 方法推断无副作用
3. **凭证安全** — 让用户在浏览器中手动输入密码，不要在对话或代码中传递密码
4. **操作前确认** — 写操作（创建/修改/删除）前必须告知用户并等待确认

### 登录流程

```bash
agent-browser open https://console.addx.live/
agent-browser snapshot -i
# @e1 = input[type="text"] 用户名, @e2 = input[type="password"] 密码
# 需要本人输入时，采用平台登录接管规则：
# 通过实际可用工具将本任务页面置前，让用户直接输入凭据并完成登录。
# 不把密码放入命令、代码、聊天或工具参数。
# 若用户只需辅助点击登录按钮，在其填写完成后操作实际按钮。
agent-browser wait --load networkidle
# 有界检查页面状态，并用 /user/info 核验目标身份；跳转本身不足以证明身份
```

### 导航操作模式

导航到目标页面的标准步骤：

```
1. 找到目标菜单组的 .arco-menu-inline-header，点击展开
2. 等待 .arco-menu-inline-content 显示（display 不为 none）
3. 在子菜单中找到目标 .arco-menu-item，点击
4. 等待页面内容加载（通常等待表格或表单出现）
```

也可以直接导航到已知路由（更快）：

```
直接访问 https://console.addx.live/<路由前缀>/<页面名>
例：https://console.addx.live/sharing/cloud-bill-admin
```

### 原生 Token 的 OpenCLI 命令

可用原生 API 可用 OpenCLI 非浏览器命令封装，保留平台原生 raw Authorization Token；使用 LOCAL/non-browser 执行方式，不将私有 API 标为匿名 PUBLIC，也不为这类读取强制依赖 Browser Bridge。凭据由调用方私有注入进程环境，不能作为参数或写入配置。读取业务前核验目标身份；仅输出明确列，拒绝输出完整用户对象、权限秘密或 Token。使用 typed auth/timeout/execution/empty 错误。

调整读取超时须有真实页面或 API 响应时长证据，并限制到已核验的具体端点；其他接口默认预算保持不变，不新增全局环境/CLI 覆盖或自动重试。保留原始 typed timeout 失败；离线修复与模拟测试只证明实现，必须重新执行本机、远端原生消费者并对照网页，才能确认真实成功。

本机和远端必须分别实际运行 OpenCLI 命令；直接 HTTP 或本机 CLI 受限租约不代替远端原生 OpenCLI 证据。临时远端 runtime/adapter 放独立目录或唯一命名空间，清理只删除本任务创建的资源，不修改原有用户配置。全站读写完整性按逐页面/动作清单和真实执行证据核验，不能把源码路由目录或两个示例命令算完整覆盖。

Console 写命令必须按页面意图区分新增与编辑：同一个 saveOrUpdate 后端可能在缺 id 时创建，UI 显示只读的字段也可能被后端接受修改。编辑命令要求已有目标 id，并保留 UI 不可修改字段；未知角色、资源、状态或部署契约时不执行。原值提交仍可能更新修改人/时间，不属于只读验收；打开并取消编辑表单只证明 UI 契约，不证明写入成功。

查询型 POST 应根据实际页面请求和服务查询行为判定，例如列表分页；禁止从 HTTP 方法推断副作用。反之，名为 edit 的服务也可能在目标记录不存在时 saveOrUpdate 新增，写命令必须核验目标存在并区分创建与编辑，不能依赖端点名称。

分页读取验收必须至少包含非首页数据，验证尚未配置的记录及合法 null 字段；保留空值，不把空配置丢弃、填造为零或当作登录失败。首屏全部字段非空不能证明整页数据契约。

Pack 厂关联的 save 是整体替换语义，省略电芯厂/型号可能删除现有关系；空关联列表可能清空工厂配置。写命令应先读取完整现状并生成新增/删除差异，让授权覆盖实际删除范围，禁止把局部 payload 当追加。只读查询无需调用 save。集合型型号和关联结果按稳定 ID/型号排序后比较，两端原始顺序不同不能直接判为数据不一致。

生产计划详情把号段数值和 seqLength 分开返回，读取命令须保留前导零；校验长度与数值范围，不能根据数值重造不同的 SN。详情使用用户已指定或列表实际返回的记录 ID，仍由后端执行真实权限检查。

同一资源列表和详情可能有不同计算字段：入库列表计算 remainBatteryCellNum，详情可能返回 null。原生读取保留实际零值/空值；不能用 truthy 判定丢掉零，也不能把 null 自动转换为零。逐接口对照网页请求，而非假设列表与详情完整对象相同。

历史日志接口可能返回全部记录，CLI 输出 limit 不等于后端分页；明确区分请求范围与展示范围，不宣称已限制服务器读取量。只查询既有历史日志，不用创建/修改操作制造验收样本。

云服务商品读取保留 price 和 currency 原值，包括零价和不同币种，不能把 $/￥ 自动转换或仅比较格式化金额。列表的空日期可能为空字符串；展示为 - 不代表接口返回 null。详情额外字典/展示字段不应冒充业务值或掩盖列表差异。

云账单分组参数可能不是记录类型等值筛选：App 与非 App 分组保留实际 recordOemType。当前月 expected 是预估标记，不能称为已结算。分页金额与整个查询的 summaryAmountUs/summaryAmountCn、totalNum 分开比较，不能用首页小计替代全范围汇总或跨币种相加。

账单详情与汇总是不同统计口径，不能要求详情 total 等于汇总的 num。详情依据实际 tenant 和日期范围，默认只查单应用单月；输出默认省略个人用户 ID/订单号，明确记录这些未覆盖字段，不把脱敏结果宣称全字段覆盖。

分成规则必须区分客户/工厂服务分支：工厂列表查询可能自动关闭过期激励并 updateById，不能当作无副作用读取或直接导航触发。只读任务停止该分支；客户列表未配置记录可 id=0、比例 null，以客户代码识别，不能把 null 改为零或把 id=0 当编辑目标。

成本参数查询可能有隐式初始化：缺少年份/类型记录时 queryDevideCostList 会 insert 12 个月成本。只读任务不能把它封装成 read 命令或打开触发查询的成本页；先追踪嵌套查询服务，确认部署版本与无写入条件。不得用生产查询探测“是否已初始化”，因为探测本身可能写入。以 BLOCKED_READONLY_SIDE_EFFECT 记录具体操作，其他独立读取继续验收。

前端页面名与 API 路径不必一致；缺少映射时可读取当前部署路由 chunk 的请求封装，再对应后端 controller/service。前端发布资源标识不是后端部署版本证明。工具响应截断导致 JSON 解析失败时不得按空列表或 PASS 处理；用页面渲染的明确列及原生完整解析结果对照，报告实际比较范围，不保存完整型号对象。

硬件部件参数的 paramValue 是可选值定义，value 才是已保存值；读取同时区分原值和标签，保留字符串 0、空串、null，不把选项列表当保存值。硬件 functionType 与软件功能参数分开核验。凭据类参数码的值脱敏，报告只记录本次对照的参数范围，不把几个参数成功算全型号覆盖。

部件/部件组页面可能把 parameterCount=0 渲染为横线；原生结果保留数字零，网页对照注明展示映射，不将零转换为 null。部分供应商名称可能由后端硬编码占位，不能当作真实供应商身份；仅输出已核验业务列。无分页的固件构建平台列表，CLI limit 仅限制输出，不代表服务器读取范围。

写 adapter 的部署/权限 evidence 参数只是调用者提供的证据标识，不能自动证明当前部署或授权。默认 dry-run、计划 hash 和本地写开关不代替用户对实际新增/修改/删除范围的授权；未执行并读回的生产写入一律不算真实验收。

角色定义必须按平台真实 ID 语义校验：客户端的渠道客户角色可合法 roleId=0，不能统一使用正整数检查把它当作空配置。保留 type/customerType 的零值；负数或非整数仍拒绝。角色定义、用户成员和权限细项分开读取，定义列表成功不证明成员或实际动作授权。

生产工艺和角色接口可能返回全部数据，由前端分页或 CLI 展示 limit；返回总量可能已经由服务过滤，不能当作数据库所有记录。保存实际比较字段和数量；生产工艺扩展对象或材料规则没有输出时明确未覆盖。

电池生产计划新增会预留生产 SN 号段；源服务可限制客户端身份、所属厂商与可编辑状态，且全局同批次号段冲突不能由当前客户端列表单独证明。仅用户名/LDAP推断、普通 evidence 字符串或模拟上下文不能证明实际客户类型、全局冲突与写权限；离线计划不是可提交业务写能力，未完成真实授权及部署核验时不执行。

4G 分成协议 sim-sharing-rules 的 customer/factory 是查询分组，不切换当前身份。正常用户类型检查仍由后端执行；它的工厂 SELECT 分支不同于有自动更新的云服务工厂分成查询，不可混为一谈。type/statisticsMode=0 固定金额、1阶梯比例，保留零金额/比例。有效期为 Unix 秒，不按毫秒解码；展示日期和原始秒数分开核验。customer-codes/manufacturer-codes 仅企业元数据，不读取联系人或个人账号；limit 为展示范围，返回总数独立记录。

硬件型号筛选保留合法枚举零值：modelType=0 是 PCBA 型号，releaseStatus=0 是未发布；使用 releaseModelStatus 字典，不误用其他模块同名发布枚举。料号 materialNo 是模糊匹配且可能有前导零，不能转数字。新增筛选的离线请求契约与已有默认列表通过不等于该筛选真实验收；真实读取要使用独立筛选并对照当前网页，空字段样本不能冒充非空筛选覆盖。

设备类别保存可能建立新版本并替换该版本的部件组关联；编辑必须核验已有 ID、保留页面禁改编码，并完整列出下一版本关联及移除差异。saveAndRelease=true 会触发发布，不可把保存草稿与发布混为一谈。仅实现读取前置和 dry-run 且 submit 禁用的命令，应明确标为计划能力；未验证部署、动作授权、实际提交与读回前不能宣称业务写接口就绪。

月份筛选须以实际接口与页面绑定为准，不能把邻近端点的旧 DTO 注释套用到当前账单接口。月份范围使用完整 YYYY-MM、成对且起止有序，保留当前分组语义；客户字典选项不证明该客户在指定月有账单。客户字典按企业代码排序比较，展示 limit 不等于服务器分页；账单验收报告保存数量、摘要及匹配结论，避免保留金额明细。

厂商对接类型字典保留数字零枚举，产品类型与对接方式分别核验；字典有某个方式不代表当前资源存在该方式的记录。默认列表、独立筛选和组合筛选分别保存实际结果；只有几条数据时不创造记录来验证第二页。创建时间的 UTC 原值与网页时区格式分别保留和比较，网页没有显示修改时间时不宣称比较了修改时间。字典与厂商辅助 SELECT 链需单独核验，不混同其他带隐式更新的工厂查询。

部件组详情可能过滤已删除参数，而保存检查当前版本的完整参数映射；param 接口还可能读取发布版本。详情空或 paramNum=0 不能证明保存没有隐藏关联副作用。参数推进版本且工站 ID 不变时，也不能仅凭拟提交 ID 保留就保证新版本关系保留；提交前核验真实版本关联契约。文件类型 save 若使用 SQL REPLACE，按替换语义记录外键/触发器与竞态风险，不称普通 UPDATE；后端名称校验缺陷不能代替调用方严格输入校验。无法证明这些条件的命令只生成候选计划，明确禁用提交和发布，不计真实写验收。

设备类别与部件组详情分别核验：类别版本字段不代表组详情也有版本，响应未提供的字段不能补造。组列表参数数与详情参数数可以不同，保留各端点真实值并记录差异；未追清版本、删除过滤或关联口径前，不判断为数据错误或全局空组。详情验收包含非空参数编码样本，只读取明确允许的编码、数量与基础字段，避免完整 DOM 或对象泄露参数值、定义、文件链接。网页只显示关联名称时仅核验名称或存在性，不能宣称已核验关联 ID；未显示的版本、时间和子参数等字段列入未覆盖。

电量计列表与详情使用不同元数据列，保留 versionTime=0 等合法值，文件 URL 不输出或访问。前端注释掉的筛选即使原生 API 支持，也只能标记原生筛选已验，不能宣称网页控件完备。仅编辑弹窗提供详情时，先核验打开和辅助请求无业务写副作用，再定位实际可见且标题匹配的弹窗，读取允许字段后取消；隐藏的其他弹窗不能作为目标证据。供应商名称的空值与横线按真实映射比较，查询源码的疑似关联错误只记录，不能擅自修复或将显示一致视为供应商归属正确。

文件类型删除和文件重命名规划仍受业务写授权限制：删除前检查完整类型文件集合，包含未发布或禁用文件，非空时拒绝，不隐式递归删除。重命名只接受 ID 与名称，状态变更可能触发发布关联更新，不把 available/version/upload/release 混入名称规划。读取可能生成预签 URL，只保留必要元数据，不输出、不访问、不参与计划 hash；显示时间不是并发版本。部署、权限、并发契约未证明时硬禁提交，离线规划不能算真实写验收。

功能映射母版列表按 componentId 分组，空列表的 CLI EMPTY_RESULT（退出码 66）不是读取成功；两端同样失败不代表 PASS。详情可使用 components 实际返回的既有组件 ID 作候选查询，即使没有保存母版，也可读取当前软件参数；必须标为既有组件候选，不能宣称已有母版覆盖。网页当前查看入口为 add-edit-function-mapping 的 operation=check：仅比较组件名、结构计数及可见表单保存按钮缺席，不读参数值或完整表单；参数 ID 未呈现在 DOM 时不声称网页 ID 对照。硬件参数数量不等于软件参数数量，空软件参数样本不能覆盖非空映射。

最低固件配置列表的型号与固件版本是配置元数据，不是构建产物目录；响应没有通用 ID 时不要强行要求 ID。历史查询仅用实际列表的型号，后端按时间降序返回该型号全部记录，CLI limit 只限制输出；记录 returnedTotal/truncated，不宣称服务器分页。日志只输出型号、ID、时间等许可字段，排除操作人和内容；网页按真实操作时间表头抽取时间列，未呈现 ID 不声称 UI ID 比较。时间格式由后端 GMT+8 注解决定，不擅自按 UTC 转换；读取无需打开新增/编辑弹窗或调用保存、构建、发布。

厂商对接详情 DTO 未回显 ID 时，requestedId 仅作请求来源；列表已有 ID、详情厂商及类型分别核验，不能补造版本或更新时间。查看页的级联 watcher 可能自动发 POST 编码规则校验，需追踪其 SELECT 链，不能凭查看页名称忽略它；文件元数据列表与下载、上传分开验收。仅提取许可表头的记录数量、状态和上传日期，不输出接口地址、文件名、操作人或文件内容，不点击下载；状态枚举与 UTC 到页面时区映射分别比较。网页仅显示规则名称而未核验 ID 到名称字典时，规则 ID 仍标为原生已读、网页未比较。

最低固件配置的新增/编辑在后端采用 upsert，并插入操作日志；新增还有固件类型、大小、哈希、路径和加密字段占位值，不能称为单字段无副作用更新。minimum-firmware-write 默认 template 无凭据或网络，create/edit 仅生成候选计划，需完整当前固件列表和实际 PCBA 型号前置；编辑要求当前固件预期值。分页快照和预期值不等于服务端 CAS，也不证明部署、生命周期和授权；未知数据库唯一约束/隐藏元数据/下游影响时禁用提交。OpenCLI 可注入内部参数来源字段，运行层仅剥离已确认的内部字段再严格校验；业务 JSON 的未知字段仍拒绝，不能为兼容 CLI 放宽业务输入。

绑定工艺配置详情可能忽略网页传入的 artPlanId，只按型号聚合多方案与已有工艺，并在内存组装默认部件组；组数与工艺数是返回视图数量，不证明已保存配置或单方案隔离。使用实际列表型号，未知或多行型号查询可失败，不创建样本规避。列表类别占位横线与详情实际类别分别保留，配置数零可能显示横线，不修正原生零值。仅比较基础型号字段、工艺名及每工艺组数，不收条码、完整配置值或操作日志；内部 ID 未渲染时不称网页 ID 对照。辅助接口即使 handler 名含 save，仍须追到真实服务，纯枚举返回与实际数据库写入分开判断。

测试项管理的 info 查询在没有配置时会插入测试项管理记录，并初始化厂商映射；只读任务不能通过打开查看页来探测是否已有配置，也不能仅凭列表 ID 假定可安全调用。列表辅助 initTestItemManage 是查询与 DTO 统计，和详情的数据库初始化分开审计；安全列表可继续读取，详情明确记录隐式写入缺口，等待无初始化的部署查询契约，不创建测试样本。

测试项现有列表和未发布候选是不同端点与资源范围：默认空审核状态查现有记录，审核状态“未发布”走 new-nosave 候选，不把它当现有记录的简单 status=0 筛选。PCBA 与整机型号仅按已审计分支读取；候选无已保存管理 ID，计数可能 null，不能捏造 ID 或把 null 改为零。网页许可列只对照型号、工艺配置计数、发布状态和时间，未显示的类别/项目数/ID单列未覆盖，尤其不要点击候选“查看”触发 info 初始化。

绑定工艺保存按型号+工艺删除旧关联再重插，不按方案 ID 隔离；缺组或未选子部件可能移除旧关联，数组位置会重排实例序号。saveAndRelease=false 也可能把被重写的已发布行改成草稿，不能称为保持发布状态的保存。查询的默认/过滤/合并视图缺完整原始行、发布状态及方案关联，不能用作全量替换现状。没有权威完整已保存状态、并发条件与真实部署契约时只做意图/就绪审计，不生成可提交 payload；普通证明字符串或客户端布尔不得解除阻断，事务及后续失败风险单列核验。

测试项型号标签切换可只刷新辅助字典，表格仍保留旧分支数据；选中标签不证明请求已切换，必须点击查询并核对实际 modelNoCategory 参数和新表格。重置可能自动回到 PCBA 默认并查询，不能假设只清空审核状态；恢复整机分支时重新选择型号并查询。跨分支验证记录筛选状态与请求，再比较原生数据，避免把旧表格误判为服务返回错误。

测试项管理写流程要逐页面审计自动加载与实际发布链：详情/编辑及复用的 info 可初始化记录；save 重置状态，非空工厂配置可删除遗漏的工艺/工厂对及重插子项，空集合不等于保持父状态。返回详情过滤缺失项目/参数并补脚本及预签 URL，不能当完整已保存原状回传。batchsave 可自动进入发布并创建 PR；cancel 也可能删除 Git 分支。未核验完整状态、部署与授权时只保留离线意图审计，不打开这些页面或调用这些接口；历史声明不是实际 handler 存在证明。

工艺保存默认发布并重置草稿状态；ext 为存量 JSON 合并，空参数和 raw ext 路径可能不同，不能把普通 JSON 当完整替换或删键指令。手动生成条码类型的规则非空检查不证明规则存在、归属或可用。网页编辑的 route.query 快照不是权威并发前置；发布可能重算工厂全部方案，跨异步线程事务不能凭注解认定。未核实当前完整状态、授权、CAS、规则和删除契约时只做离线就绪审计，不输出可执行写 payload。

生产方案多型号分支由 fresh有界 `production-plans` 第一条 modelCount>1 的同一响应行派生内部 ID，再固定 `production-plan` 详情，禁止历史ID/跨行名称拼接。列表 distinct modelCount 与详情 relation appearances分别记录，不因新分支增加唯一命令。仅导航 readonly查看路由且完整辅助请求先证明只读，不能进edit/clone/publish/delete；型号原文joined、工艺名及结构数量分别DOM比对，工厂显示label不证明ID，legacy分类sentinel不推DOM绑定，默认组占位不证明保存配置。
