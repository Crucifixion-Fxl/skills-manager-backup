# 问卷设计与受访者负担

本参考把有效测量组织成一份自然、易答、可实施的问卷。先使用 `research-scope-and-measurement.md` 明确目标与证据。

## 1. 建立问卷主线

- 选择一个 primary decision spine。Supporting modules 必须与主线共享决策依赖或自然回答语境；受访者相同不是拼在一起的充分理由。
- 先分配 evidence source，避免让用户重复报告遥测已有事实。
- 模块按推断依赖与用户记忆旅程排序，而非内部功能架构。
- 测 independent/unaided demand 时，先问外部行为、当前做法和自然问题；当前产品体验居中，未来概念最后出现。
- 概念与术语 just-in-time 暴露。开场、section 描述和 transition 同样会 priming。
- 敏感、开放、复杂比较和未来假设通常后置；但不能为“容易”破坏 unaided/aided 顺序。

## 2. 开场与第一题

开场只保留用户决定是否参与所需的主题相关性、必要信任/隐私信息和平台没有提供的真实成本。删除内部 brief、产品宣传、分支说明、泛化安慰语及平台已显示的时长/进度。

至少比较两个合理首题候选，依据：

- 用户是否能立即回答；
- 是否需要精确回忆或产品术语；
- 题干和选项首屏长度、移动端扫描成本；
- routing 价值和与下一题的衔接；
- 对后续答案的 priming 风险。

首题避免开放题、grid、长列表、精确次数和高敏感任务，除非它们对资格或核心推断不可替代。题干短不代表低负担，选项数量、换行和难区分程度同样重要。

## 3. Burden budget

逐题估计：理解、记忆检索、判断、选项映射、交互和敏感压力；路径级再估计典型/最长时间、实际展示比例、选项扫描行数、开放题、复杂任务和概念切换。

用 `estimated_percent_shown × seconds_when_shown` 辅助比较真实总体负担。优先：

- 只向具备经验的 cohort 展示；
- 缩短选项并减少难区分比较；
- 用渐进诊断代替一次性长杂列表；
- 删除可从前题、routing 或遥测推导的问题；
- 在保持同一 estimand 和行动颗粒度时选择更轻方案。

阈值只触发替代方案审查，不机械判错。高负担题若有独特决策价值可以保留，但需说明为什么没有等价轻量方案。

## 4. 题干与题型

- 一题只给一个清晰任务；短句优先，但保留必要条件和时间锚点。
- 使用目标用户自然词汇，不用内部缩写或未经解释的产品分类。
- 用户应能一次阅读后用自己的话正确复述题意。
- 单选、多选、尺度、排序、开放题和 routing 的选择必须匹配目标 estimand。
- Grid 仅在各项目共享同一回答维度且移动端确实更易答时使用。
- 敏感或可能被评价的行为使用中性表达，并提供合法退出方式。

## 5. 选项设计

每组选项检查：

- 直接回答题干同一维度，语法和抽象层级一致；
- 单选互斥；多选也尽量避免同义、嵌套和高共现重叠；
- 覆盖目标用户有依据的常见答案；`Other` 只覆盖未知尾部；
- 不用“我不感兴趣/不满意”等结论同义反复冒充原因；
- 数值和频率区间连续、无重叠并覆盖边界；
- `None / Not applicable / Don't know / Prefer not to answer` 语义适用且与实质选项排他；
- 数量、长度和交互适合移动端。

### 原因题

先画简化 causal map，区分触发事件、近因机制、具体表现、稳定偏好、情境限制和结果描述。父原因与子原因、机制与症状、跨场景习惯与单次事件原因不应在同一单选集合竞争。

需要上位机制和具体动作时，优先两阶段：先选少量互斥机制，再只向相关人群追问细因。扁平列表也可以成立，但需同层、可区分、符合目标指标且负担可接受。

## 6. 选项顺序与随机化

每道封闭题记录：

```yaml
option_order:
  strategy: natural | randomized | rotated | fixed
  fixed_option_ids: []
  rationale:
```

- 时间、频率、强度、旅程阶段和量表使用自然顺序，不随机。
- 无自然顺序的原因、内容、渠道等分类通常随机；需要平衡首位暴露时可轮换。
- `Other / None / Don't know / Not applicable / Prefer not to answer` 固定末尾，仅随机实质选项。
- routing、piping 与分析引用稳定 option ID，不引用显示位置。
- 若平台不能实现“随机实质项 + 固定语义项”，可为整题保留固定顺序并记录风险；不要仅为轻微顺序效应增加重复题或复杂分支。
- 答案随机化、问题顺序、概念卡顺序、视觉位置和 respondent version assignment 是不同随机化单位，不能互相替代。

## 7. 跨题去重与顺序污染

为每题记录 `primary_construct + measurement_role + event/time window + user task`。若两题共享大量选项概念、同一事件或形成 incidence→priority、actual→unmet 等链路，检查：

1. 后一题新增什么不可从前题推导的指标？
2. 它是否会改变不同业务动作？
3. 是否只展示给真正需要回答的人？
4. 是否有同等有效的更轻设计？

仅有内部构念名不同、报告表格不同或“想多了解一点”不能证明增量价值。保留期望/实际差距、可靠性或质量检查类重复时，预先写明比较方法。

一般行为/事实先于评价、偏好和意向；unaided 开放探索先于相关封闭选项。General-first 与 specific-first 都可能产生 context effect，按目标选择并记录限制。

## 8. 完卷审查

用若干有依据的典型、反例和边界视角走过实际分支，检查复述、记忆依据、选项映射、被迫作答、顺序污染和负担峰值。合成走查只能发现候选问题，不能证明发生率、完成率或真实文化适配；生产级规则见 `research-assurance-and-delivery.md`。
