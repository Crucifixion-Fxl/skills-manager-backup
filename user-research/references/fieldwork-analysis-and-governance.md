# Fieldwork, Analysis and Governance

完整研究计划按风险使用本参考；低风险局部建议只检查相关部分。

## 1. Sampling and recruitment

记录 target population、sampling frame、eligibility、exclusions、招募渠道、quota/segments 和经验新鲜度。样本量依据研究目标：

- 定性研究说明需要覆盖的差异、反例和停止依据；
- 描述性问卷说明目标比例精度、设计效应和预期有效率；
- 分群比较说明各组最低可解释样本；
- 实验说明最小有意义效果、power/false-positive 控制和分配方式。

便利样本、客户邮件、App 弹窗、社群或自愿报名的覆盖和 self-selection 限制必须写进结论。激励不得迫使参与，也不能与回答内容挂钩。

## 2. Pre-analysis plan

在 fieldwork 前定义：

- 每个结论对应的 metric/theme、numerator、denominator 或 qualitative evidence rule；
- eligibility、routing、partial response、missing、don't know 和异常值处理；
- primary 与 exploratory analyses；
- subgroup cuts、最低样本和多重比较风险；
- weighting/calibration 是否需要及依据；
- 开放题/访谈编码、反例和一致性检查；
- 与 telemetry 联结的 key、许可、时间窗与 linkage bias；
- 结果如何触发、否定或延后具体动作。

不要在看到结果后静默改变主要指标或排除规则。

## 3. Data quality and soft launch

按方法设计小规模 pilot/soft launch，检查招募理解、完成时间、breakoff、跳题、异常短时长、重复/机器人答卷、straightlining、设备差异和记录完整性。预先定义 continue / pause / revise 条件。

Attention checks 会增加负担且可能误伤认真用户，只在风险和用途明确时使用。质量规则优先标记与敏感性分析，不无依据地静默删除。

研究开始后修改 instrument/protocol 时记录版本、时间、受影响样本和可比性。改变构念、选项、逻辑、刺激或招募条件通常需要新版本或新 wave，不能把前后数据无说明合并。

## 4. Privacy, consent and data governance

- 区分 anonymous、confidential 和 identifiable；只承诺实际能做到的状态。
- 最小化 PII，说明用途、访问范围、保存期限和退出/撤回方式。
- 录音、录像、屏幕、位置、自由文本和 telemetry linkage 分别评估并取得适当同意。
- 联系信息/激励发放数据尽可能与研究答案分离。
- 不把原始响应、token、邮箱、录像或其他个人数据提交进 skill 仓库。
- 删除、对外共享和正式传播是独立动作；遵守组织政策和适用法律，不由 skill 猜测法律结论。

未成年人、弱势人群、医疗/法律/财务/安全或高度敏感主题升级伦理、人工审查和数据保护要求。

## 5. Accessibility, language and inclusion

- 使用目标参与者能理解的语言和渠道，不把产品熟练度当作一般读写能力。
- 翻译关注构念与回答选项等价，而非逐字一致；重要跨语言比较需要 review/pilot。
- 检查键盘、屏幕阅读器、alt text、颜色、字幕、对比度和移动端呈现。
- 为无法使用默认交互方式的人提供合理替代，同时记录 mode effect。
- 跨语言、设备或招募渠道合并时检查 measurement 和 coverage 差异。

## 6. Reporting boundaries

报告区分事实、参与者自述、观察、统计估计与研究者推断。呈现不确定性、反例、样本覆盖和不能推广的范围。不同方法结果冲突时先检查 population、时间、情境和测量差异，不以“多数证据”简单投票。

## 7. Decision closeout and reuse

研究计划先写明准备支持的决定；真实研究结束后，再记录研究建议和 owner 的实际决定。两者不能合并：agent 可以基于证据提出建议，但不能把建议冒充已获批准的产品动作。

最低 closeout 包含：

| 字段 | 要求 |
|---|---|
| original decision | 研究原本准备降低哪个决定的不确定性 |
| decisive evidence | 真正影响判断的证据、样本/来源和时间 |
| conclusion strength | supported / directional / unresolved，以及关键限制 |
| research recommendation | 基于证据建议采取、避免或继续验证什么 |
| owner decision | adopt / reject / defer / further_validation / pending |
| rationale | Owner 的理由；未知时不代填 |
| next action | 已确认的产品、设计、数据或研究动作 |
| owner and timing | 已明确时记录；不猜负责人或日期 |
| validation | 后续用什么信号判断决定是否奏效 |
| remaining unknowns | 本轮没有解决或新出现的问题 |

没有 owner 决定不阻止研究报告交付，状态保持 `pending`。创建任务、通知他人、排期或启动后续研究属于新的外部动作，需要相应授权。

为后续 evidence inventory 保留可检索的最小研究元数据：主题/决定、目标用户与情境、日期、方法、样本范围、关键结论、限制、材料位置和是否已被新证据取代。不要把原始 PII 或受限记录复制进通用知识库；旧结论在用户、产品或市场变化后必须重新检查适用性。
