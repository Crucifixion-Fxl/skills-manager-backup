# 统计分析默认规则

本文件提供通用默认值，不替代研究设计、数据结构和领域判断。任何统计方法都应先说明：研究问题、分析单位、比较对象、分母和希望估计的量。

## 1. 分析顺序

1. 检查研究工具版本、样本来源、跳题与缺失。
2. 先报告原始分布和有效样本量。
3. 再进行与研究问题直接相关的比较或模型。
4. 最后考虑派生指标、分档和探索性分析。
5. 同时报告效应大小、方向和不确定性，不只报告显著性。

## 2. 百分比与分母

- 百分比写为 `x% (n/N)`，或在图表中清楚标注分母。
- 每题分母优先采用实际有资格且有效作答的人数，而不是整份问卷总样本。
- 多选题标注“多选，合计可超过 100%”。
- 加权结果必须同时说明权重来源，并在重要结论处区分加权与未加权结果。
- 小样本单元优先显示人数，并根据隐私规则合并或隐藏，避免用精确百分比制造稳定错觉。

## 3. 有序量表

有序量表默认展示完整分布，并可补充中位数、四分位数或预先定义的 Top-box / Bottom-box。

- 均值可用于描述，但必须符合团队惯例并避免暗示相邻选项距离完全相等。
- 推断方法根据设计选择：独立组、配对重复测量、聚类样本和有序因变量需要不同方法。
- 可选方法包括有序回归、秩方法、置换检验或 bootstrap；不要因为数据是量表就自动套用同一个检验。
- 不要把所有 0–10 分题都称为 Likert，也不要把购买意愿称为 NPS。

## 4. 多重比较

先定义“检验家族”：哪些比较共同回答同一个问题，并会一起影响同一个决策。

- 主要、事前规划的少量比较可以按研究方案执行，并透明报告全部结果。
- 大量探索性比较应控制假阳性风险；验证性场景更常关注 FWER，筛选与发现性场景可考虑 FDR。
- 不按一个固定的比较数量机械触发某种校正，也不把未经校正的偶然显著结果升级为主要发现。
- 同时提供效应量和置信区间或其他不确定性表达。

## 5. 样本充分性

不使用通用的 `n<30`、`n≥200` 等阈值直接判定“能否下结论”。样本是否够用取决于：

- 目标估计精度或最小关注效应；
- 抽样与招募偏差；
- 组间是否平衡、是否存在重复测量；
- 缺失、跳题和权重；
- 结论的重要性与错误成本；
- 定性研究是否已达到与目标匹配的信息充分度。

无法进行正式功效或精度评估时，用可观察事实写限制，例如置信区间较宽、某分组人数很少、样本只覆盖活跃用户。不要仅以样本量标签替代判断。

## 6. Top、Bottom 与 Net

若问卷让受访者选择最重要、最不重要、最喜欢或最不喜欢的项目，这些 Top/Bottom 结果属于原始测量，应分别报告。

使用 Net（如 Top% − Bottom%）前检查：

1. Top 与 Bottom 是否测量同一构念的相反方向；
2. 每位受访者的选择机会是否可比；
3. Top N 与 Bottom M 不同时，直接相减是否会系统性偏移；
4. Net 是否会掩盖“同时被很多人喜欢和不喜欢”的两极分化；
5. 该指标是否真的对应一个决策，而不只是为了产生单一排名。

若使用 Net：

- 写清公式、分母和必要的机会归一化；
- 同时展示 Top 与 Bottom 原始分布；
- 事后提出的 Net 标为探索性；
- 对高 Top、高 Bottom 的项目单独提示分化，不能只看净值。

## 7. 综合排名与分档

综合得分、优先级排名和高/中/低档可以帮助阅读，但不是天然存在于数据中的类别。

- 说明纳入哪些指标、方向、权重和缺失处理。
- 分档规则应透明，例如业务门槛、聚类方法或明确的展示切点。
- 研究前确定的规则可作为主要分析；事后形成的分档可以使用，但标为探索性或展示性。
- 对合理的替代权重或切点做敏感性检查；结论容易改变时，不应给出稳定的档位标签。
- 不要为了整齐而强制每档拥有相同数量的项目。

## 8. 交叉分析

交叉分析用于解释“哪些人、在哪些情境下不同”，而不是把所有题目两两相乘。

优先满足以下条件：

- 分组变量在研究问题中有明确作用；
- 有 respondent-level 数据和正确分母；
- 每组覆盖足以支持所用表达；
- 差异可能改变产品、运营或后续研究动作；
- 同时检查绝对差异、相对差异与不确定性。

没有稳定或有决策价值的差异也是结果，可放入证据层，不必挤进主要结论。

## 9. 开放题计数

- 代码频次的分母通常是该开放题有效作答人数，而不是总样本。
- 一条回答可以有多个代码时，合计可超过 100%。
- 代码频次反映在当前样本中被提及的程度，不等同于总体需求发生率。
- 稀少但高风险或高价值主题可单独报告，但必须标明罕见和证据性质。

## 10. 相关、预测与因果

- 观察性调查通常支持描述和关联，不自动支持因果。
- 自报意愿是态度或预测信号，不等同于真实购买、留存或使用行为。
- 过去行为通常比抽象未来预测更接近实际约束，但也可能受可得功能和历史环境影响。
- 因果语言只用于随机实验、可信准实验或有充分识别论证的分析。

## 11. 最小统计检查清单

- [ ] 题目 wording、编码、分母和缺失已核对
- [ ] 原始分布先于派生指标呈现
- [ ] 主要与探索性分析已区分
- [ ] 多重比较策略与研究目的匹配
- [ ] 效应量与不确定性已提供
- [ ] Net、综合排名和分档的规则透明且保留原始组成
- [ ] 交叉分析只在有数据基础和决策价值时进入主要结论
- [ ] 关联、预测和因果措辞没有越界
