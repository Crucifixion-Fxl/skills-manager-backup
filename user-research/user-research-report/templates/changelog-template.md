## 复核状态

- [ ] 摘要、正文、图表和附录已同步
- [ ] 关键数字与分母已复算
- [ ] 新增或撤回分析已正确标注

- [ ] 需要时已准备对外同步说明（发送需另行授权）

> Git 或文档历史可以记录文件变化；本模板记录的是会影响研究理解和决策的语义变化。两者可互补，但不要求所有研究都使用 Git。
