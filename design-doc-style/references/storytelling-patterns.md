# 首页叙事与文档站统一风格

参考当前仓库的 `scripts/templates/skill-hub.html` 与 Device Cloud `src/pages/HostProduct/original/homeMarkup.ts` / `style.less`。复用可验证的排版与交互，不依赖对方仓库运行时；随仓库分发的资源须符合所在项目许可和发布规则。

## 页面密度

| 页面 | 展示方式 | 详细内容 |
| --- | --- | --- |
| 首页 | 大标题、一句解释、独立流程演示、行动入口；章节之间留白 | 链到正文，首页不放流程说明长段落 |
| Catalog | 统一过滤、搜索、分层图、可组合能力 | 触发词、来源、细节在详情中保留 |
| Loop / 架构正文 | 总览图、局部节点目录＋右侧单项详情、证据与引用 | Owner / Gate / 输入输出 / 待验证项完整写出 |
| 文化与通用方法 | 同一主题、明确章节、短论点＋真实例子 | 保留完整原文，使用成对背景/文字色 |

首页一节只回答一个问题；Human×Agent 如何协作与 Skill 能力如何分层是两个段落，各有标题与演示区域。禁止把多个标题、长解释和图塞进一个巨型卡片。首页解释建议一个短句；图中标签说明职责，重复介绍移到详情页。文字精简必须改写，不能用 CSS 行数裁剪丢内容。

## 导航与整合页

文化、通用工作方法、Best Practices、规范与约定在同一导航下按区呈现，独立总览页沿相同结构完整整合，菜单与正文复用目录数据。业务 Loop 导航只放真实主业务 Loop，不混入团队通用方法；目标子 Loop 从所属业务页进入。菜单布局偏移使用独立 CSS translate，避免 Motion 的 transform 步骤覆盖定位；窄屏清除偏移、使用局部滚动。

## 主题与语义

默认主题是 `tokens.css` 墨绿杂志风。已使用夜色首页的站点可叠加 `hub-theme.css`：保留夜色背景和浅色纸面模式，统一首页、目录、正文与文化页。主题表面色不代表业务状态；主线 mint，人的判断/待验证 orange，外部依赖 blue，阻断 rose；violet 保留给正文中的待决。

`hub-theme.css` 的 `--atlas-*` 是正本；`--bg` / `--paper` 等仅是旧页面兼容别名。不要单独给案例栏发明配色。按当前页面 body/html 的 `data-theme` 切换；正文、卡片、pre 和提示块必须同时指定成对的背景/文字色。

## 演示与动效

优先使用渐入、步骤状态切换、反馈线与滚动进度。Motion / Framer 只是实现选项；没有 runtime 时完整静态内容仍可读。首页演示需提供暂停，手动选择暂停自动推进；动画只在视口内运行，切换/销毁时清理 observer 和计时器，隐藏页面暂停。启用 `prefers-reduced-motion` 时停止自动演示与持续动画，保留按钮与键盘操作。

节点详情采用 `detail-explorer.css/js`，固定阅读区而非固定整页；不用动效掩盖切换后页面跳高。独立文档内联所有资源，多页站点用本地分发资源；禁止公网 CDN。对屏幕阅读器使用真实标题、figcaption、焦点与选中状态，装饰场景 `aria-hidden`。

## Loop 正文的信息结构

按「目标指标 → 流程图 → 节点执行契约 → 结果反馈 → 能力与引用」组织。指标名称、评价口径和待绑定状态直接显示，不藏在附录。目标、基线、窗口未填写时明确标示，不能把设计目标写成已取得结果。

节点详情用独立字段表达：责任 Owner、执行者、输入、AI 动作、输出证据、通过条件，以及通过/失败的去向。Owner 是结果责任，不能暗示其手工执行；人的判断与授权单独列明。用真实的短条目改写源内容，不使用截断、关键词拼接或仅把长文折叠来降低密度。复杂 Gate 的完整条件和原始证据清单保留在同节点的技术依据中；摘要不得省掉决定能否推进的约束。

结果反馈用独立的三个步骤：AI 汇总证据 → 人通过协作通道判断 → AI 更新假设与 Eval 并再执行；其下并排列出评价信号、不可牺牲的护栏、人的判断范围。具体角色与系统不能用泛化示意取代。原始指标定义、证据链与未验证能力保留；引用按正本责任分组，不重复正文说明。

同系列页面采用相同字段结构；每条 Loop 保留自己的指标、输入输出与 Gate。硬件并行支线、实验分组、供应链成本等不同机制不得被统一模板抹平。

## 验收

- 桌面/窄屏、明暗主题都检查：首页短文案、两张图独立、无整页横向溢出。
- 图与局部目录切换同步；目录点击不改变页面高度，右侧只显示一个节点。
- hash 刷新、键盘、无 JS、打印全部正文可读；打印后恢复原选择。
- 普通正文对比度至少 4.5:1；检查浅底浅字、提示块、反模式与代码。
- 动效开启/暂停/减少动态效果都能阅读与导航；业务目标必须区分目标和已取得证据。
