上下文与目标

人通过对话定义目标、边界与通过条件；Agent 整理可复用上下文。

执行者：AI；人通过对话判断与授权。

输入：目标、来源、候选版本及当前适用边界。

输出与证据：目标、约束与来源链接。

阶段 Gate：目标与 Eval 有可追溯来源，权限边界明确。

下一轮：失败证据回到责任节点；待验证项保持可见。

Agent 执行

Harness 接通工具、权限和真实环境；Agent 执行并采集证据。

执行者：AI；人通过对话判断与授权。

输入：目标、来源、候选版本及当前适用边界。

输出与证据：候选版本、执行日志与实际产物。

阶段 Gate：版本与证据对应；未接通环境记录为缺口。

下一轮：失败证据回到责任节点；待验证项保持可见。

Eval 与反馈

Agent 运行 Eval，失败后修正复验；架构与价值取舍回到人的判断。

执行者：AI；人通过对话判断与授权。

输入：目标、来源、候选版本及当前适用边界。

输出与证据：成功/失败结果、复验记录与判断请求。

阶段 Gate：不以完成声明代替结果；未验证目标保持待验证。

下一轮：失败证据回到责任节点；待验证项保持可见。
