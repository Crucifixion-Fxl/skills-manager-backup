# Memory 极简写入

适用于项目 `AGENTS.md` / `CLAUDE.md`、目录指引和 auto-memory。

- 每次新增规则块默认 **≤5 条、≤10 行、约≤200 字**；只写长期约束、非显然决策和必要入口。既有安全门禁、用户约束不能为凑字数删减。
- 教程、代码、案例、完整 ADR、登记表、执行回执和进度放独立文档；memory 只留一句约束及相对链接。工具索引每工具一行，不复制 API 说明。
- 写前读取、语义去重，只增量更新相关块；保留项目阈值、例外及其它内容。不要以精简为由批量重写既有 memory。
- `AGENTS.md` / `CLAUDE.md` 共用一个权威来源，另一份引用；同一软链目标只写一次，不沿软链写出授权项目。子目录只写特有规则，默认≤20行，不复述根规则。
- auto-memory 正文同样精简：结论、适用范围、必要原因、证据入口；不记录临时进度或易过期业务数值。只有已授权写入场景才写，只读审查仅建议。

写后报告路径和新增行数。此页是 skill 的写入规约，**不要把本页全文再写进用户 memory**。
