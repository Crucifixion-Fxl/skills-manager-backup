# 报告结构与范围控制

报告结构应服务于读者要做的决定，而不是机械复刻问卷顺序，也不应把所有题目都塞进主要结论。

## 1. 先建立范围覆盖表

写作前建立内部覆盖表：

| 研究目标 | 对应证据 | 当前可回答程度 | 报告位置 | 后续缺口 |
|---|---|---|---|---|
| 目标 A | Q1、行为数据、访谈主题 | 充分 / 部分 / 不足 | 主报告 / 证据层 | 需要补什么 |

规则：

- 每个已确认的研究目标必须得到结论、当前状态或明确的“证据不足”。
- 每道题应可追溯到研究目标或质量检查；无法对应时，不强行制造结论。
- 重要题目不能因不符合叙事而消失；次要题目可以只出现在证据层。
- 超出原研究范围的新问题可以作为后续假设，不能伪装成本研究已回答的问题。

## 2. 根据使用场景选择形态

### Quick findings

适合回收途中、阶段性同步或需要快速判断是否调整招募时使用。必须显著标注快照时间、当前样本、仍可能变化的结论和不能用于最终决策的内容。

### 决策导向主报告

适合大多数跨职能读者。建议顺序：

1. 研究回答了什么、没有回答什么；
2. 最重要且证据最稳的发现；
3. 对当前决策的含义与选项；
4. 关键分化、反例和风险；
5. 方法与限制；
6. 证据附录。

### 完整研究报告

适合需要长期留档、方法复核或复杂混合方法研究。可增加研究背景、样本与招募、逐主题证据、分析细节、开放题 codebook、题目级结果和复现材料。

### 证据附录 / 数据附录

适合承载题目级分布、次要交叉分析、派生指标细节、表格和去标识化引文索引。它补充主报告，不替代主报告。

这些形态可以组合；篇幅由决策风险和证据复杂度决定，不设固定章节数或固定首屏行数。

## 3. 主报告与证据层

一项结果进入主要发现，通常应同时满足：

- 与已确认的研究目标直接相关；
- 数据与测量能够支持该表述；
- 影响一个真实决策、风险或优先级；
- 不是仅由偶然切分或单个异常值驱动；
- 关键限制可以在结果附近说清楚。

否则可放入：

- 证据层：真实但次要、尚不改变决策；
- 探索发现：值得后续验证，但不是主要证据；
- 不报告：重复、无效或有隐私风险，内部留痕说明原因。

## 4. 派生分析如何进入结构

- 原始题目结果按研究目标组织。
- 事前规划且测量逻辑成立的综合指标，可以进入主要发现。
- 事后形成的 Net、分档、聚类或交叉分析可以带来启发，但应标为探索性，并让读者看到关键原始分布。
- 探索结果只有在效应明显、解释合理、稳定性可接受且会改变下一步行动时，才升级到主报告；否则留在证据层。
- 不用“统计显著”单独决定版面优先级。

## 5. 产品与业务状态核对

报告中涉及现有功能、价格、权益、流程或上线状态时：

1. 与可靠的产品资料或 owner 确认当前状态；
2. 区分“用户不知道”“用户未使用”“产品未提供”和“数据无法判断”；
3. 若状态尚未确认，使用条件性措辞，不把假设写成事实；
4. 外部资料用于解释背景时，应注明来源和访问时间。

## 6. 行动建议的边界

研究报告可以提出决策含义、可选动作和验证建议，但要保持证据边界：

- `发现`：数据直接显示什么；
- `解释`：一种合理机制，仍可能有替代解释；
- `建议`：基于发现、约束和风险提出的选择；
- `验证`：下一步如何降低关键不确定性。

建议应能回答“谁可以做什么、解决什么问题、还需验证什么”，但不能把研究团队的偏好包装成唯一答案。

## 7. 题目级完整性检查

交付前核对：

- [ ] 所有研究目标均有覆盖状态
- [ ] 关键题目与关键开放题未遗漏
- [ ] 筛选题、质量题和背景题没有被误写为用户需求结论
- [ ] 主报告没有被低价值逐题复述淹没
- [ ] 证据附录能够追溯主要数字和引文
- [ ] 不稳定交叉分析没有混入主要结论
- [ ] 新假设与原研究结论已分开
