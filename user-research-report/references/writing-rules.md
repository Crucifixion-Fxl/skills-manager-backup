# 研究报告写作规则

目标是让非研究人员容易读懂，同时让专业读者能复核证据。清晰不等于下结论更猛，中立也不等于把报告写得平淡。

## 1. 从读者问题出发

每一节优先回答：

1. 我们看到了什么？
2. 这对当前问题为什么重要？
3. 证据边界在哪里？
4. 下一步有哪些可选动作或验证方式？

标题尽量写成有信息量的发现句，而不是“Q5 结果”或“用户反馈”。标题强度不得超过证据。

## 2. 分开四种内容

- **事实 / 发现**：可以直接从数据、观察或引文核对。
- **解释**：对机制或原因的合理推断，需注明不确定性和替代解释。
- **建议**：基于证据与业务约束提出的动作选项。
- **限制**：会改变读者如何理解或使用结论的边界。

不要求每一句解释都加警告符号。可以通过小标题、段落标签、措辞和版式区分；但关键解释与限制必须靠近对应发现，不能全部藏在报告末尾。

## 3. 保持有行动力但不中立失守

推荐写法：

> **发现：** 较多受访者在完成任务前退出，主要集中在步骤 B。
> **意味着：** 步骤 B 是当前流程最值得优先检查的摩擦点，但问卷不能证明它是退出的唯一原因。
> **可选动作：** 先用日志或可用性测试区分信息不清、操作失败和价值不足，再决定改文案还是改流程。

避免：

- “用户显然想要……”
- “数据证明上线该功能一定提升收入……”
- 只列百分比，不说明对决策的意义；
- 为了保持中立而只写“有些人这样、有些人那样”。

## 4. 术语与语言

- 使用受众熟悉的产品语言；必要的统计或研究术语在首次出现时解释。
- 不一概禁止英文或缩写。团队通用词可以保留，但不要让读者必须查术语表才能理解主要结论。
- 受访者原话与报告语言不同时，可提供原文和忠实翻译；说明翻译方式。
- “显著”“趋势”“因果”“代表性”等词只按其技术含义使用。

## 5. 数字表达

- 关键比例给出人数与分母，例如 `42% (38/91)`。
- 百分点变化写“增加 8 个百分点”，不要写成“增长 8%”除非确实是相对变化。
- 多选题、跳题和加权数据在图表附近说明。
- 小样本或宽不确定区间避免使用过度精确的小数。
- 图表标题、正文和附录使用同一口径。

## 6. 派生指标的写法

第一次出现 Net、指数、综合排名或分档时，说明：

- 它由哪些原始结果组成；
- 如何计算；
- 为什么适合当前问题；
- 是主要分析还是探索性分析；
- 哪些原始分布必须同时保留。

不要把展示性分档写成数据天然形成的“人群类型”或“需求层级”。

## 7. 不确定性措辞

按证据强度选择动词：

- 描述：显示、报告、选择、提及、观察到；
- 关联：相关、伴随、在该组更常见；
- 解释：可能意味着、与……一致、一个可能原因是；
- 因果：导致、提升、降低——仅在设计支持时使用。

“无显著差异”不等于“完全相同”，“没有观察到”不等于“没有发生”。

## 8. 建议表达

建议优先写成：

`证据 → 决策含义 → 可选动作 → 风险/验证`

建议可以排序，但排序依据要透明，例如影响范围、证据强度、实现成本、可逆性或战略匹配。研究证据不足以决定的部分应交还 owner，而不是替其做未经授权的取舍。

## 9. 发布前语言检查

- [ ] 标题没有超过证据强度
- [ ] 事实、解释、建议和限制可区分
- [ ] 关键数字带分母
- [ ] 术语对目标读者可理解
- [ ] 事后分析已标为探索性
- [ ] 负面、反例和分化没有被隐藏
- [ ] 没有把态度直接写成行为或商业结果
- [ ] 行动建议保留了必要的验证条件
