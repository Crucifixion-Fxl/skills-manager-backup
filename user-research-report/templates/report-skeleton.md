## 证据层最低内容

- 研究目标完整登记；
- 受访者实际看到的原始题干和选项；
- 每题完整人数、分母和分布；
- 派生指标、阈值、合并口径和敏感性；
- 统计方法、交叉分析去向、剔除与数据质量；
- 去标识化开放题原文和编码方法；
- 返回主报告的链接。

## 交付检查

- [ ] 核心标题均由紧邻数据直接支持，没有因果、策略口号或未确认阈值。
- [ ] 每个范围内研究目标在主报告有独立答案或状态。
- [ ] 人数、分母、原始措辞、开放题追溯和隐私规则已满足。
- [ ] 涉及共同出现、路径或分群的结论有联合分布；低增量分析没有挤进核心结论。
- [ ] 致命限制在正文，外推限制在证据边界，方法细节在附录。
- [ ] 主报告与证据层版本、链接、目标和共享事实通过一致性校验。
- [ ] 已共享版本的数据或结论发生重大变化时，已经留痕。
