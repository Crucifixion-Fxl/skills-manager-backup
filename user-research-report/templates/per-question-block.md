# 单题证据块模板

仅在题目需要独立展开时使用。主报告不必机械复制每道题；证据层应保证范围内结果可追溯。

## 通用题目块

```markdown
### [题目 ID] [读者可理解的主题]（[题型]，n=[有效作答数]）

> **受访者看到的原始问题：** [wording]

**可答人群 / 分母：** [显示逻辑与分母定义]

| 结果 | 人数 | 占比 |
|---|---:|---:|
| [选项或分值] | [n] | [x%] |
| ... | ... | ... |

**直接发现：** [只描述数据能支持的结果。]

**解释或决策含义（如需要）：** [与直接发现分开，并说明替代解释。]

**限制（如会影响理解）：** [缺失、小单元、顺序效应、测量边界等。]
```

多选题注明合计可超过 100%；矩阵或排名题可按项目展开，但要保留同一分母和题目任务。

## 有序量表块

```markdown
### [题目 ID] [主题]（[量表范围]，n=[N]）

> **原始问题：** [wording]

| 选项 / 分值 | 人数 | 占比 |
|---|---:|---:|
| ... | ... | ... |

**描述汇总：** 中位数 [ ]；四分位数 [ ]；[如适用，均值与置信区间]
**预先定义的摘要（如适用）：** [Top-box / Bottom-box 的定义和结果]
```

不得默认把 0–10 题称为 Likert，也不得默认使用均值、Wilcoxon、bootstrap 或 FDR。方法按 `references/statistical-defaults.md` 和实际设计选择。

## Top / Bottom 选择块

```markdown
### [题目 ID] [最重要 / 最不重要等任务]（最多选 [N]，n=[N]）

> **原始问题：** [wording]

| 项目 | 被选人数 | 占可答者比例 |
|---|---:|---:|
| ... | ... | ... |
```

如果同一研究同时有 Top 与 Bottom：

- 先分别展示两者；
- 只有逻辑适用时才增加 Net 或综合矩阵；
- 说明选择机会、公式和 `planned / exploratory` 状态；
- 检查高 Top、高 Bottom 的分化，不用固定阈值自动贴标签。

## 派生指标块

```markdown
### [分析 ID] [指标或分析名称]（[planned / exploratory]）

- **回答的问题：** [research question]
- **来源：** [题目 ID / 数据字段]
- **计算或模型：** [公式、权重、分组和缺失处理]
- **结果与不确定性：** [effect / interval / robustness]
- **必须同时查看的原始结果：** [链接或表格]
- **主要限制：** [会怎样改变使用方式]
```

## 开放题块

```markdown
### [题目 ID] [主题]（开放题，n_open=[N]）

> **原始问题：** [wording]

**编码信息：** [coding package / codebook 版本 / 处理方式]

| 主题 | 提及人数 | 占该题有效回答 | 说明 |
|---|---:|---:|---|
| ... | ... | ... | ... |

**代表性引文：**
> “[逐字或标明处理方式的引文]” — [去标识化情境标签]

**反例或重要少数：** [如有，说明频次和重要性]
```

主报告不默认展示 respondent ID；可追溯 ID 放在受控证据包。主题可以多重编码时注明合计可超过 100%。

## NPS 块

只用于标准推荐意愿题。

```markdown
### [题目 ID] [推荐对象] NPS（0–10，n=[N]）

> **原始问题：** [wording]

- Promoters（9–10）：[n/N, %]
- Passives（7–8）：[n/N, %]
- Detractors（0–6）：[n/N, %]
- **NPS = Promoters% − Detractors% = [值]**

[保留完整 0–10 分布或链接到证据表]
```

## Self-check

- [ ] 原始 wording、题型、显示逻辑和分母可见
- [ ] 人数与百分比一致
- [ ] 原始分布没有被均值、Net 或分档取代
- [ ] 方法与实际设计匹配，没有套用固定检验
- [ ] 事实、解释、建议与限制可区分
- [ ] 开放题引用编码包，且引文隐私与可追溯性兼顾
- [ ] 事后分析明确标为探索性
