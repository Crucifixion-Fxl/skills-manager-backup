# Quick Findings 简版骨架

适用于 `depth=quick`。根据用途删减栏目，但不得删除会改变结论理解的限制。

```markdown
# [研究主题]：Quick Findings

> [若为 interim：**阶段性快照，非最终结论。**]
> 截止：[时间]｜有效样本：[当前 n / 目标 n]｜收集状态：[进行中 / 已关闭 / 未知]｜工具版本：[版本]

## 现在能看到什么

1. **[直接、无宣传性的发现或状态]** [n/N (%)]。
2. **[发现或状态]** [n/N (%)]。
3. **[发现或状态]** [n/N (%)]。

## 对当前问题意味着什么

- **已经缩小的范围：**[证据支持排除、保留或继续观察什么。]
- **仍不能决定：**[尚缺样本、行为证据、业务约束或测量。]

## 样本与数据质量

- [样本/配额状态]
- [完成、退出、时长、重复、逻辑或缺失信号]
- [相对上一可比快照的变化；不可比则说明原因]

## 下一次更新看什么

- [需要达到的样本、分群或质量条件]
- [范围内尚无稳定答案的研究目标]

> **证据边界：**[紧邻写出会限制使用方式的条件。]

[完整证据或冻结数据快照链接]
```

## 简版检查

- [ ] 用途、阶段、深度和数据截止时间可识别。
- [ ] interim 被醒目标为非最终结论；final 有明确冻结依据。
- [ ] 每条数字有人数、分母和可追溯证据。
- [ ] 核心研究目标均有答案或状态，没有因篇幅被静默遗漏。
- [ ] 没有基于滚动查看的数据捕鱼、提前停止或趋势夸大。
- [ ] 简版没有把分析解释或临时行动写成研究事实。
