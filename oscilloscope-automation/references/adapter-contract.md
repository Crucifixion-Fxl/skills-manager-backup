# 型号适配契约

## 识别

适配器必须根据 `*IDN?` 返回的厂商和系列匹配，不得仅依据资源字符串或 USB VID/PID 推断型号。匹配结果区分：

| 状态 | 含义 |
|---|---|
| `hardware_verified` | 当前型号和固件已完成实机只读验证 |
| `adapter_matched_firmware_unverified` | 系列命令匹配，但当前固件未实测 |
| `manual_family_unverified` | 只依据同系列编程手册，未完成当前型号实测 |
| `unsupported` | 无适配器，不执行型号专属操作 |

只有 `hardware_verified` 允许执行适配器命令。其他状态只用于身份识别和能力提示，不得绕过执行门禁。

## 能力

每个适配器至少明确以下接口是否可用：

| 接口 | 契约 |
|---|---|
| `measure` | 把统一测量名映射到厂商命令，同时完成单位归一化 |
| `screenshot` | 返回解包后的图像负载，不把 TMC 头写入文件 |
| `waveform` | 自动保存并恢复传输配置，返回带时间和电压标定的数据 |
| `snapshot` | 只读取适配器承诺能够恢复的设置，并写入快照模式版本 |
| `restore` | 只接受由同一设备、同一模式版本快照产生的完整字段，禁止任意 SCPI 写入 |
| `next_error` | 读取厂商错误队列，结果进入每次操作的 JSON |

## 接入

新增型号时：

1. 新增独立适配器文件，不在通用 CLI 中堆厂商判断。
2. 以官方编程手册建立候选命令，以实机返回和错误队列确定支持状态。
3. 至少验证身份、一个数值测量、截图、波形读取、快照恢复和错误队列。
4. 用不同固件时保留固件边界，不把同系列文档兼容写成实机兼容。
5. 为命令映射、单位换算和 TMC 解析增加离线测试。
