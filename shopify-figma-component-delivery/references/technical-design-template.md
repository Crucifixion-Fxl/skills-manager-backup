| 安全区 | <文字和主体不可进入的裁切范围> |
| 极端比例 | <超宽、矮屏、横屏、高长宽比手机的规则> |
| 运营素材约束 | <建议比例、缺失移动图、比例异常时回退> |
| 稳定占位 | <width/height/aspect-ratio，防 CLS> |

实现约束：

- 永不通过非等比缩放填满容器。
- 不把所有屏幕统一为一个固定像素高度；尺寸规则同时考虑宽度和必要时的高度 media query。
- 使用 `cover` 时必须能说明每类屏幕裁掉哪一侧以及主体为何仍安全。
- 使用 `contain` 时必须定义露出区域的背景颜色、纹理或延展方式。
- 桌面/移动独立素材必须共享业务内容和 alt 语义；装饰图使用空 alt 或 CSS 背景，内容图提供有效 alt。
- 图片为首屏 LCP 候选时，source、预加载和 fetch priority 策略必须与性能预算一致；非首屏不得无理由抢占带宽。
