## 2. 开始配置

1. 进入 Shopify 后台的主题编辑器。
2. 打开 <页面名称/模板>。
3. 在左侧找到“<Theme Editor 中的组件名称>”。
4. 修改后先在桌面和手机预览中检查。
5. 点击保存。保存到 Draft 只更新预览主题，不会自动发布到正式网站。
